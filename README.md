# Image Classifier

A small image-classification project built with PyTorch and torchvision. The notebook trains a convolutional neural network on the CIFAR-10 dataset, evaluates its accuracy, saves the trained model, and uses the model to classify local image files.

## Features

- Downloads and loads the CIFAR-10 training and test datasets.
- Normalizes 32 x 32 RGB images for training.
- Trains a compact convolutional neural network.
- Reports test-set accuracy.
- Saves the trained weights to `trained_net.pth`.
- Classifies `data/Test 1.jpg` and `data/Test 2.jpg`.

## Project Files

```text
.
|-- main.ipynb          # Training, evaluation, and prediction workflow
|-- requirements.txt    # Python dependencies
|-- data/                # Downloaded CIFAR-10 data and local test images
|-- trained_net.pth      # Generated model weights
`-- README.md
```

## Requirements

- Python 3.10 or newer
- Jupyter Notebook or VS Code with the Jupyter extension
- A CPU is sufficient; CUDA can be used if PyTorch is installed with CUDA support

## Setup

Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install the dependencies:

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Open `main.ipynb` in VS Code or Jupyter and select the `.venv` Python kernel.

## Running the Notebook

Run the notebook cells in order. The dataset cell downloads CIFAR-10 into `data/` the first time it runs. Training uses a batch size of 32 for 30 epochs and writes the model weights to `trained_net.pth`.

The final cell expects these files:

```text
data/Test 1.jpg
data/Test 2.jpg
```

Add your own 32 x 32-compatible RGB images with those names, or edit the `image_paths` list in the notebook.

## Windows Notes

The notebook sets `num_workers=0` because multiprocessing data loaders can be unreliable in some Windows environments. If training is slow, use a smaller number of epochs for experimentation and increase the batch size when your available memory allows it.

## Git Notes

The CIFAR-10 archive is downloaded locally and should not be committed. The generated model file can also be regenerated by running the notebook. Keep large dataset archives out of GitHub because individual files over 100 MB are rejected.
